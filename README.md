**🧠 QuizApp – SwiftUI Trivia Game**  
A fun and interactive quiz app built with SwiftUI for iOS.    
Users can test their knowledge, track their score, and enjoy a smooth, animated experience.  


**📱 Features**  
✅ Multiple-choice questions  
✅ Dynamic scoring system  
✅ Progress bar and animations  
✅ Clean SwiftUI design  
✅ Local JSON based question loading

**🧰 Tech Stack**  
Language: Swift 5  
Framework: SwiftUI  
Architecture: MVVM
Platform: iOS 17.6+  
Data: Local JSON  
Tools: Xcode 16, SF Symbols, Combine  


**⚙️ Installation**  
Clone the repository  
git clone https://github.com/yourusername/QuizApp.git  
Open QuizApp.xcodeproj or QuizApp.xcworkspace in Xcode.    
Build and run on iPhone Simulator or device (iOS 16+).
